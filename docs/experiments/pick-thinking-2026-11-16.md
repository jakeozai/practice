# 추천 모델 '생각' 끄기 비교 (2026-11-16)

질문: 맞춤 추천(gemini-2.5-flash)이 답하기 전에 하는 '생각'을 끄면 비용이 줄어드는데, 추천 품질이 떨어지는가?
사용자 지시: 품질이 떨어지면 끄지 않는다. **결론: 떨어진다. 끄지 않는다.**

## 방법
- 같은 시각(01:48, 01:55 UTC)의 같은 공고 풀로 가상 구독자 10명(`lib/match/personas.ts`)을 두 번 돌렸다. 저장·발송은 하지 않았다.
- `/api/cron/picks-personas?thinking=off`는 생각 끔, 파라미터 없이 부르면 실제 메일과 같은 기본값이다.
- 두 번 모두 10명 전원 모델이 골랐다(규칙 대체 0건).

## 비용 (AI Gateway 실측)
| | 10회 | 1회 | 입력/출력 토큰 |
|---|---|---|---|
| 생각 켬(기본) | $0.1226 | $0.0123 | 42,129 / 4,585 |
| 생각 끔 | $0.0243 | $0.0024 | 42,129 / 4,664 |

생각 끔의 비용은 보이는 토큰 값과 정확히 같다. Gateway가 `thinking: {type: "disabled"}`를 Gemini 설정으로 넘긴 것이 확인됐다.

## 품질
생각을 끄면 다음 문제가 생겼다. 생각을 켠 쪽에서는 같은 문제를 찾지 못했다.

1. **프롬프트 예시를 그대로 베낌, 해 본 적 없는 경력을 씀 (3/10)**
   - 번역가, AI로 웹앱 만드는 간호사, 모션그래픽 작업자의 도전 이유에 프롬프트 예시 문장 "썸네일 만들던 감각에 Ideogram 시안을 더하면…"이 그대로 들어갔다.
   - 세 페르소나 모두 썸네일 경력이 없다. 웹앱 간호사 쪽은 공고가 프라이머 배너인데 "의류 제품 배너"라고 썼다.
   - 규칙 "해 봤다고 쓰지 않는다"를 어긴다.
2. **근거 없는 경력 (2/10)**
   - 파이썬 개발자: "스크래핑으로 이미지 처리 경험이 있으니"
   - 번역가: "AI 번역 시스템 평가 경험"
3. **맞지 않는 공고로 개수를 채움 (2/10)**
   - 간호사와 한국어 AI 데이터 작업자에게 "AI Trainers Network - Odia"(오디아어 원어민 대상)를 맞춤으로 골랐다. 간호사에게는 "Small Business Owner" AI 교육도 함께 골랐다.
   - 생각을 켜면 두 공고를 빼고 간호사 1개, 데이터 작업자 2개만 보냈다. 맞는 게 없으면 줄인다는 개인화 원칙(CLAUDE.md)과 맞는 쪽은 켬이다.
4. 나머지(디자이너, 카피라이터, 3D, 회계사)는 비슷했다. 고른 공고가 대부분 같았고, 이유 문장은 켬 쪽이 프로필 사실을 더 정확히 인용했다.

  - 2026-11-16 고침: 제목이 말하는 언어를 규칙으로 읽어 `languages`에 더한다(`lib/jobs/language.ts`, 처리 때 `buildJob`, 추출 프롬프트도 보강). 열린 공고 51건을 같은 규칙으로 고쳤다(`workers/backfill-languages.ts`와 같은 계산). 오디아어 공고는 이제 가상 구독자 10명 누구의 규칙 후보에도 들지 않는다(고치기 전 5명).
