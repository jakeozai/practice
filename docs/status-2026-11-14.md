## Freelancer.com API 약관 (freelancer.com/about/apiterms, 11/14 확인)

- 허용: API로 자체 웹사이트·서비스를 만들고 연동하는 것.
- 조건: 데이터는 성능 목적의 캐시로만, **24시간 안에 새로고침**, 강한 암호화로 저장·전송, Freelancer 서비스를 **복제·경쟁하는 용도 금지**.
- 덕잡의 대응: 매일 수집으로 새로고침, **목록에서 빠진 의뢰는 jobs째 삭제**(`purgeRaw`), Supabase 저장 시 암호화(기본 제공). 덕잡은 요약과 원문 링크만 보내고 입찰·고용 기능이 없다.
- 리스크: "경쟁 금지" 조항은 해석 여지가 있다. 문제가 되면 Freelancer 소스만 끄면 된다(`sources.active = false`).

## 개인화 적용 (같은 날 오후, 사용자 결정)

### 원인 조사 — "영상 스킬과 상관없는 일감이 왔다"

| 원인 | 내용 |
| --- | --- |
| 메일이 프로필을 안 봄 | Phase 1 발송이 전원에게 같은 목록(최신 → 시급 → 한국어 작업 우선)을 보냈다. 11/14 메일 3개는 한국어 라벨링·법률 일감 |
| 지원 가능한 영상 일감 부족 | 수집된 영상 공고(Mercor·Invisible·Welo·TransPerfect)는 전부 미국·영국·캐나다·중남미 등 거주자 한정 → 지역 규칙이 정상 제외 |
| 페이지 수집처 미수집 | 수집이 소스를 차례로 돌며 285초 예산을 쓰는데, 이름순 첫 페이지 소스인 Mercor가 새 페이지 수백 개(1.1초 간격)로 예산을 다 써서 **OneForma·OpenTrain은 한 번도 수집되지 않았다**(`last_fetched_at` 없음). OpenTrain은 일감 약 1,600개, 영상·크리에이티브 제목 약 75개 |

### 결정

- 프로필이 있는 구독자에게는 그 사람의 AI 분석을 **철저히 따른 3개**만 보낸다. 종류를 섞지 않는다. 3개 모두 "오늘 안에 하고 싶게": 카드마다 추천 이유와 **오늘 할 일**(지원·입찰 한 가지), 메일 제목도 개인화.
- 맞는 일감이 없으면 그날은 보내지 않는다(공용 목록으로 채우지 않음).

### 구현

| 항목 | 내용 |
| --- | --- |
| 규칙 (`lib/match/fit.ts`, `concepts.ts`) | 한국어 프로필 ↔ 영어·한국어 공고를 잇는 개념 사전. 제외: 없는 작업 언어, 영어 2단계 이상 차이, avoid 목록, 본인 출연·녹음류, 주당 시간 초과, 최저 시급 미달, 주 분야 밖 자격 요건, 쓰지 않는 프로그래밍 언어의 개발 일, 프로필과 무관. 점수: fields 순서(5→3.4) > AI 우선 추천(4) > 전문 분야(3) > 기술(2.5) > 경력(2), 도구 언급·보수·신선도 가산 |
| 선택 (`lib/match/pick.ts`, `prompts/digest-pick.md`) | 모델이 규칙 상위 12개에서 3개 + 이유·오늘 할 일·제목. 실패하면 규칙 순위와 규칙 문구로 대체 |
| 저장·일정 | `digest_picks`(0012). 05:30~05:50 KST 처리 실행이 먼저 picks를 만들고, 06:00 발송이 빠진 사람만 채운다. 같은 날 재실행은 같은 메일 |
