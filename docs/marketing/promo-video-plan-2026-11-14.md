# 덕잡 홍보 영상 기획 3안 (인스타 릴스·스레드, 2026-11-14, 검토용)

## 레퍼런스에서 본 것

1. "AI 부업" 콘텐츠는 과장·사기성이 판친다: "GPT로 월 1,400만원", "달러 채굴", "하루 130만원", 상담 링크 유도 계정. 데이터라벨링 사칭 사기 경고 글도 돈다. → 덕잡은 반대로 "진짜 공고, 실제 금액, 사기 거름"이 차별점.
2. 믿음을 얻는 글은 실제 숫자를 보여 준다: Outlier 후기($9.18 페이팔 입금), Upwork 1년 후기(첫 달 $303 → 단가 올리기). 작고 구체적인 실제 숫자가 신뢰를 만든다.
3. 릴스 형식: "POV 훅 + 바로 증거(화면 녹화)"가 앱 소개에 가장 많이 쓰인다. 단, 막연한 POV는 식상하고 구체적인 디테일이 붙어야 한다.
4. 첫 3초 설계, 반박하고 싶어지는 주장이 조회수를 끈다(하이아웃풋클럽 멤버 릴스 분석).
5. 매끈한 AI 생성 영상은 조회수는 나와도 저장·공유가 낮다. "우리만 찍을 수 있는 장면", 다음 편으로 이어지는 시리즈가 오래 간다(1point).
6. 인스타 책임자 모세리: 시청 시간·좋아요·공유(보내기)가 핵심 신호, 해시태그는 도달을 늘리지 않는다.
7. 스레드는 판매 글을 잘 보여 주지 않는다. 개인 목소리·기록형·한 줄로 답할 수 있는 질문이 반응을 받는다(1인 런칭 기록: 런칭 글 조회수 40, 신청 0).

한계: 로그인된 브라우저·Apify를 못 써서 게시물별 좋아요·공유 수는 수집하지 못했다(검색 결과 본문만). 촬영 전에 인스타 릴스 탭에서 "해외 부업", "AI 부업" 상위 영상 2~3개를 직접 보고 첫 화면을 확인하길 권한다.

## 공통 규칙
- 9:16, 1080×1920, 자막 필수(소리 꺼도 이해되게). 위 220px·아래 420px은 앱 버튼이 덮으니 글자를 두지 않는다.
- 수익 보장·과장 금지("월 ○백 가능" 같은 말 안 씀). 금액은 실제 공고 금액만, "조건은 원문 기준" 표기.
- 실제 아침 메일 화면을 쓰되 구독자 이메일 주소는 가린다.
- 음악은 업로드할 때 인스타 앱 안의 오디오로 붙인다(파일에 넣지 않음).

## A안. "06:00, 눈 뜨면 와 있는 해외 일감" (POV + 실제 화면) — 20초

목적: 덕잡이 뭔지 한 번에 보여 주는 대표 영상(프로필 고정용).

| 초 | 화면 | 자막 |
| --- | --- | --- |
| 0–2 | 어두운 방, 머리맡 폰. 05:59 → 06:00, 알림 "오늘 엄선한 해외 일감 5개" | POV: 눈 뜨면 해외 일감 5개가 와 있다 |
| 2–9 | 엄지로 메일 열기 → 카드 스크롤(실제 메일 녹화) | 유튜브 자막 $90 · AI 답변 평가 시간당 $25 · 로고 시안 $120 |
| 9–13 | 카드 확대: 한국어 요약·추천 이유·오늘 할 일 | 영어 공고를 한국어로 3줄 요약 |
| 13–17 | 커피 한 모금, 노트북에서 원문 열기 | 지원은 원문에서 직접. 출근 전 10분 |
| 17–20 | 로고 + duckjob.app | 매일 아침 6시, 해외 AI 일감 5개 · 무료 |

- 제작: 폰 화면 녹화 + 직접 찍는 장면 3컷(알람, 커피, 노트북). 하루면 된다.
- 강점: 서비스 이해가 가장 빠름, 공유하기 쉬움. 약점: 식상한 POV가 될 수 있어 실제 금액·실제 화면이 필수.

## B안. "AI 부업 검색하면 나오는 것 vs 진짜 해외 일감" (대비·반박형) — 25초

목적: 과장 광고에 지친 사람의 공감과 공유를 노림(도달용).

| 초 | 화면 | 자막 |
| --- | --- | --- |
| 0–3 | 화면 반으로 나눔. 왼쪽: 흔한 과장 문구 모음(직접 만든 가상 화면, 실제 계정 노출 없음) | "AI로 월 1,400만원" 이런 거 말고 |
| 3–10 | 오른쪽: 오늘 실제로 온 공고 5개가 하나씩 쌓임 | 진짜 해외 공고: 자막 $90, 3D 모델 $150, AI 평가 시간당 $25 |
| 10–18 | 체크 표시 애니메이션 | 덕잡이 빼는 것: 선입금·메신저 유도 / 한국에서 지원 불가 / 최저시급 미달 |
| 18–25 | 메일 화면 + 로고 | 큰돈 약속 대신 진짜 공고 5개. 매일 아침 6시, 무료 |

- 제작: 전부 화면·모션그래픽(얼굴 없음). 이틀.
- 강점: 반박하고 싶은 주장 + 공감 → 공유·댓글. 약점: 특정 계정을 저격하면 역풍 → 문구는 일반화한 가상 예시만.
- 스레드 버전(글): "AI 부업 검색하면 월 천만원 얘기뿐이라, 진짜 해외 공고만 매일 5개 골라 주는 걸 만들었어요. 오늘 온 공고는 이거예요 👇" + 메일 캡처 1장 + 질문 "이 중에 하고 싶은 거 있어요?" 링크는 셀프 댓글.

## C안. "오늘 6시에 온 해외 일감" 매일 시리즈 (정보·저장형) — 25~30초, 매일 또는 주 3회

목적: 저장·팔로우를 쌓는 반복 콘텐츠. 매번 새로 기획할 필요 없음.

| 초 | 화면 | 자막 |
| --- | --- | --- |
| 0–2 | 큰 숫자 "11/15 06:00" + 제목 | 오늘 들어온 해외 AI 일감 5개 (3초 안에 다 봐요) |
| 2–22 | 일감 1개당 4초: 한국어 제목, 금액, "AI로 약 2시간", 누구에게 맞는지 | 1. 유튜브 영상 한국어 자막 · $90 · 영상 편집할 줄 알면 … |
| 22–27 | 마무리 | 매일 내 프로필에 맞춰 받으려면: 프로필 링크 · 무료 |

- 제작: 그날 실제 메일 내용으로 자동 생성 가능(덕잡 데이터 → 템플릿 영상). 처음 한 번 템플릿을 만들면 매일 5분.
- 강점: "다음 편"이 있는 시리즈, 저장할 이유, 알고리즘이 계정을 파악하기 쉬움. 약점: 단독 한 편의 화제성은 낮다. 30편 정도 쌓여야 효과.
- 주의: 메일 공고를 다른 매체에 그대로 싣는 셈이라 원문 약관(Jobicy·Himalayas 출처 표기 등)을 지키고, Freelancer 의뢰는 요약·금액만 쓰고 원문 문구는 쓰지 않는다.

## 추천
- 시작: A안(프로필 고정) + B안(첫 주 도달 시험), 그다음 C안을 매일 시리즈로.
- 스레드: 영상보다 B안의 글 버전과 "만든 사람 기록형" 글이 맞는다.

## 수정 방향 (사용자 피드백): "직장인 아빠의 달러 부업" — 릴스 30초

배경 숫자(확인함): 원·달러 환율 2026-11-13 마감 1,336.7원(11월 1,330~1,365원 범위). 2025년 연평균 1,421.97원으로 역대 최고, 2000~2020년 평균은 1,128.9원. → "지금 환율이 폭등 중"은 사실과 다름(오히려 내려오는 중). "달러가 예전보다 200원 넘게 비싼 시대"로 말한다.

첫 화면 문구 후보(A/B 테스트):
1. 월급 빼고 다 오르길래, 달러로 부업 시작했어요
2. 1달러 1,300원대, 아빠가 출근 전 6시에 하는 일
3. 요즘 배운 AI, 회사 말고 해외에 팔아봤어요

| 초 | 화면 | 자막·내레이션 |
| --- | --- | --- |
| 0–2 | 새벽 거실, 아이 방 문 살짝 열림(아이 얼굴 없음). 아빠 뒷모습 | (첫 화면 문구) |
| 2–6 | 식탁 위 폰, 06:00 덕잡 알림 | 요즘 다들 AI 배우잖아요. 이걸로 바로 돈이 될까 싶었죠 |
| 6–14 | 실제 메일 화면 녹화: 일감 5개, "유튜브 영상 한국어 자막 $90", "AI 답변 한국어 평가 시간당 $25" | 매일 아침 6시, 해외 AI 일감 5개를 한국어로 정리해서 보내줘요 |
| 14–20 | 큰 글씨 계산: $90 × 1,336원 ≈ 12만 원 / 작은 글씨 "환율은 매일 달라요 · 11/13 기준" | 1달러가 1,300원대인 요즘, 달러로 받으면 꽤 쏠쏠해요 |
| 20–26 | 밤, 불 꺼진 거실, 노트북 앞 아빠(손·화면 위주), AI로 자막 작업 | 출근 전엔 지원하고, 애들 재우고 한두 시간 |
| 26–30 | 로고 + "매일 아침 6시, 해외 AI 일감 5개 · 무료 · duckjob.app" | 공고 찾는 건 덕잡이, 일은 내 AI랑 |

주의:
- 연출이면 "번 돈"을 1인칭 실적처럼 말하지 않는다(거짓 체험담은 표시광고법 문제). 금액은 "공고 금액"으로만. 실제 이용자 사례가 생기면 그때 실적형으로.
- 아이 얼굴·이름·집 주소가 보이는 물건은 찍지 않는다.
- 캡션 끝에 "해외 소득도 5월 종합소득세 신고 대상이에요(해외 일감 이용 안내 참고)" 한 줄.

스레드 글(구어체, 기록형):
"월급 빼고 다 오르는 요즘, AI 배운 걸로 달러 부업을 찾는 아빠들이 많더라고요.
해외 일감은 달러로 받는데, 1달러가 1,300원대라 $90짜리 자막 일 하나가 12만 원 정도예요.
문제는 영어 공고 찾는 게 일이라는 것.
그래서 매일 아침 6시에 해외 AI 일감 5개를 한국어로 골라 보내는 걸 만들었어요. 오늘 온 거 👇
AI 배운 거, 어디에 써먹고 계세요?"
(링크는 셀프 댓글. 본인이 아빠라면 1인칭 경험담으로 바꿔도 된다.)
