# 해외 단기 일감을 한국에서 하고 외화로 받는 것 — 법적 점검 (2026-11-14)

웹 검색으로 정리한 1차 점검이다. 출처 대부분이 은행 안내·세무 Q&A·블로그 같은 2차 자료라 최종 판단은 세무사·노무사·은행 확인이 필요하다.

## 결론

한국 거주자가 해외 의뢰인에게 원격으로 일해 주고 외화로 받는 것 자체를 막는 법은 찾지 못했다. 다만 이용자에게 신고·확인 의무가 있고(세금, 건강보험, 겸업), 덕잡 자체는 직업안정법상 직업정보제공사업 신고를 검토해야 한다.

## 이용자 쪽

| 항목 | 내용 |
| --- | --- |
| 외화 받기 | 용역 대가 수령은 금지 거래가 아니다. 은행이 수령 사유를 물을 수 있고(“용역 대가”), 큰 금액·누계는 국세청·관세청 통보 대상이 될 수 있다. 통보 자체는 불법이 아니다. 기준 금액(연 10만 달러, 건당 5천·1만 달러 등)은 자료마다 달라 은행 확인 필요 |
| 세금 | 국내 거주자는 해외 소득도 종합소득세 신고 대상(보통 사업소득, 매년 5월). 해외 플랫폼은 3.3%를 떼지 않으므로 직접 신고해야 한다. 외화는 원화로 환산, 입금·정산 내역 보관 |
| 부가가치세 | 사업자등록 없는 개인의 인적용역(도안·삽화·저술 등 시행령 제42조 열거 용역)은 면세 가능. 계속·반복적이면 사업자등록 검토. 번역 등 개별 항목은 확인 필요 |
| 해외 원천징수 | 미국 플랫폼은 W-8BEN 제출 요구. 이미 외국에서 뗀 세금은 외국납부세액공제 가능 |
| 건강보험 피부양자 | 사업자등록이 없으면 사업소득(경비 뺀 소득금액) 연 500만 원 초과 시, 등록했으면 소득이 생기는 즉시 피부양자 자격을 잃을 수 있다 |
| 겸업 | 회사원은 취업규칙의 겸업 금지 조항, 공무원은 겸직 허가(국가공무원법 제64조) 확인 |

## 덕잡 쪽

- 직업안정법 제23조: 인터넷 등으로 구인·구직 정보를 제공하는 사업은 고용노동부에 직업정보제공사업 신고. 수수료 없음, 처리 7일. 무신고 시 벌칙(자료상 1년 이하 징역 또는 1천만 원 이하 벌금, 현행 조문 확인 필요).
- 프리랜서 용역(고용계약이 아님) 정보가 이 법의 “직업정보”에 해당하는지는 해석 여지가 있다. 신고가 간단하므로 공개 전환 전에 신고하거나 노무사 확인을 권장.
- 신고하면 지킬 것: 최저임금 미달 구인정보 제공 금지, 이력서 발송 대행·취업추천서 발부 금지(덕잡은 하지 않음).
- 직접 알선(구인자·구직자 연결)으로 가면 직업소개사업(등록) 문제가 생긴다. 지금 구조(요약 + 원문 링크, 지원은 이용자가 직접)를 유지한다.
