## 2. 서비스 내용과 운영 방식
1. **수집:** 해외 기업이 공개한 채용 시스템(Greenhouse, Lever 등)과 원격 채용 보드(Himalayas, Jobicy)의 공개 공고를 공식 API로 수집한다. 구인자가 덕잡에 직접 공고를 올리는 기능은 없다.
2. **정리:** 공고마다 한국어 요약(업무, 조건, 보수, 지원 방법)을 만들고, 원문 링크를 붙인다. 원문 전체는 게재하지 않는다.
3. **선별:** 구독자가 입력한 관심 분야·기술·외국어 수준·가능 시간에 맞는 공고를 골라 하루 최대 5개를 보낸다.
4. **지원:** 구독자가 원문 사이트에서 직접 지원하고 계약한다. 덕잡은 구인자와 구독자를 연결하거나 이력서를 전달하지 않으며, 구독자 정보를 구인자에게 제공하지 않는다(직업소개를 하지 않음).
5. **해지:** 모든 메일 하단의 링크로 언제든 구독을 해지할 수 있다.

## 3. 준수사항 이행 방안 (직업안정법 시행령 제28조)
| 준수사항 | 이행 방안 |
|---|---|
| 구인자의 업체명·성명을 확인할 수 없는 구인광고 게재 금지 | 운영자가 회사의 공식 홈페이지(연락처·약관·개인정보처리방침)나 공적 등록부로 법인명과 주소·전화를 확인한 회사의 공고만 게재한다. 확인 출처와 확인일을 기록해 관리한다. 의뢰인이 익명인 플랫폼의 공고는 게재하지 않는다 |
| 구인광고에 구인자의 주소 또는 전화번호 기재, 사업자 연락처 미기재 | 메일의 공고마다 "회사 정보" 항목에 구인자 법인명과 주소(있으면 전화번호)를 표시한다. 덕잡의 주소·전화번호는 구인광고에 표시하지 않는다 |
| "(무료)취업상담·취업추천·취업지원" 표현 금지 | 웹사이트·메일·광고문에 해당 표현을 쓰지 않는다. "추천"이라는 말도 쓰지 않고 "골라 드려요", "맞춤" 등을 쓴다 |
| 이력서 발송 대행, 취업추천서 발부 금지 | 해당 기능이 없다 |
| 최저임금 미달 구인정보 | 보수가 시급으로 표기된 공고는 가장 낮은 시급이 한국 최저임금보다 낮으면 게재하지 않는다(자체 기준) |
| 거짓 구인광고 | 이용자가 공고마다 신고할 수 있고, 신고는 운영자에게 즉시 알림으로 전달된다. 운영자가 확인해 문제가 있으면 모든 구독자에게 게재를 중단한다 |

## 4. 인력과 설비
- **인력:** 운영자 1인. 수집·요약·발송은 자동화돼 있고, 운영자는 공고 검수, 신고 처리, 회사 정보 확인을 한다.
- **설비:** 클라우드 서비스를 쓴다.
  - 웹·발송: Vercel
  - 데이터베이스: Supabase
  - 메일: Resend 또는 Amazon SES
  - 요약: AI API
- **개인정보:** 개인정보 처리방침을 웹사이트에 게시한다(https://www.duckjob.app/privacy). 수집 항목은 이메일과 이용자가 입력한 프로필이고, 해지·탈퇴하면 삭제한다.
